## Description
A responsive professional portfolio website showcasing my projects and skills as a Business Information Systems student. The website features a clean design with a sidebar profile section, project navigation, and search functionality.

## Features
- **Responsive Design**: Adapts to all screen sizes (desktop, tablet, mobile)
- **Project Showcase**: Links to four key projects
- **Search Functionality**: Basic search implementation (currently demonstrates alert functionality)
- **Modern UI**: Purple-themed color scheme with clean sections
- **Sticky Navigation**: Easy access to all sections

## Projects Included
1. Basic Webpage
2. Rock Paper Scissors Game
3. Flatland Business Advisor
4. RSS Reader

## Technologies Used
- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (Basic interactivity)
- Responsive Design Principles
